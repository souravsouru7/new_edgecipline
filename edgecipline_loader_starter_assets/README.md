# Edgecipline loader starter assets

These are lightweight, editable SVG starter assets for the “Discipline Machine” intro loader.

## Included
- `svg/edgecipline-wordmark-placeholder.svg` — editable text placeholder. Replace with the official logo/wordmark artwork if available.
- `svg/edgecipline-green-sweep.svg` — green scan line and highlight.
- `svg/edgecipline-dotted-mountain.svg` — procedural dotted mountain illustration.

## Important
These are starter assets, not a finished loader. The IDE should implement the motion, timing, responsive behaviour, reduced-motion support, and integration described in the master prompt. Confirm the exact official brand spelling and use the production logo asset if it differs.

## Suggested palette
- Background: `#F4F2E9` (warm ivory)
- Ink: `#111714`
- Edgecipline green: `#16834A`
- Highlight green: `#8AF0B3`

Prefer inline SVG for animated elements so individual paths, dots, and shapes can be animated efficiently. Do not rasterize the SVGs unless necessary.
